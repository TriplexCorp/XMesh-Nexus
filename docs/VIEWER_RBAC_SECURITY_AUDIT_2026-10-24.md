# Аудит прав роли «Наблюдатель» — 24 октября 2026 года

## Модель угроз

Наблюдатель — действующий, аутентифицированный пользователь с ролью `viewer`, который может:
- использовать браузер, DevTools, `curl` и собственные HTTP-запросы;
- изменять URL, параметры, тело запросов и состояние интерфейса;
- знать произвольные ID пользователей и нод;
- входить в тот же профиль браузера, в котором раньше работал владелец.

Доверенные стороны: backend, PostgreSQL, хранилище подписок, подписанный протокол обмена с нодами. UI не является границей безопасности.

## Проверенные поверхности и меры

| Поверхность | Ограничение |
|---|---|
| `GET /api/v1/bootstrap` | Запрещённые коллекции не загружаются; разрешённые проектируются по явному перечню безопасных полей |
| `GET /api/v1/collections/{collection}` | Наблюдателю доступны только `users`, `nodes`, `squads`; ответ без секретов и произвольных вложенных объектов |
| `GET /api/v1/settings` | Только название панели; никакого `subscriptionJson`, webhook/hook, подписок и настроек клиентов |
| `GET /api/v1/security/policy` | Отказ 403, политика аутентификации и скрытый URL панели не выдаются |
| `GET /api/v1/core` | Только безопасный статус и версия, без внутренних ошибок установки |
| `GET /api/v1/nodes/{id}/runtime` | Рабочее состояние доступно, внутренние URL GeoData не возвращаются |
| `GET /api/v1/nodes/{id}/restart` | Отказ 403; GET ранее изменял состояния истёкших команд |
| `GET /api/v1/statistics/overview` | Операционная статистика доступна без имени хостинг-провайдера для наблюдателя |
| `GET /api/v1/users/{id}/subscription` и `/client-json` | Уже требуют `owner` или `admin`; наблюдатель получает 403 |
| Создание/редактирование/удаление коллекций | Только `owner` или `admin`, контроль в backend |
| Перезапуск, обновление Xray/агента, GeoData, выдача enrollment, маршруты нод | Серверная проверка прав; клиентские запреты — дополнительный слой |
| Администраторы, политика безопасности, аудит | Только разрешённые привилегированные роли |
| `localStorage` | Старый `xmeshNexusDB` удаляется при загрузке; дампы инфраструктуры больше не читаются и не сохраняются в браузере |
| Интерфейс | У наблюдателя оставлены «Дашборд», «Статистика», «Пользователи», «Узлы». Редактирование отключено и скрыто |
| MFA и собственные сессии | Самообслуживание собственной учётной записи разрешено, чужие сессии недоступны |

## Что именно исключено из данных наблюдателя

UUID/Xray ID, ссылки подписок, ключи и пароли, параметры REALITY и Xray, JSON профилей и маршрутов, хосты, устройства, адреса нод, email, Telegram ID, заметки пользователей, платёжные реквизиты, административные ключи и закрытая политика безопасности. Все поля вне разрешённого списка исключаются автоматически при расширении схемы.

У владельца и администратора исходные данные продолжают возвращаться без маскирования.

## Автоматические проверки

- В `backend/src/main.rs` есть unit-тесты отказа в изменениях, прямом чтении запрещённых коллекций и проекции чувствительных полей.
- `scripts/check-viewer-security.js` фиксирует контракты авторизации и отсутствие localStorage-кеша.
- `scripts/test-auth-integration.py` проверяет роль на реальных HTTP-эндпоинтах с PostgreSQL/Redis, включая доступ к коллекциям, пользовательский UUID, bootstrap, настройки, секрет подписки и клиентский JSON.
- `.github/workflows/backend-ci.yml` запускает проверки кода, Rust unit-тесты и интеграционные тесты.

## Важные ограничения

Это аудит **роли `viewer`** в текущем репозитории, а не гарантия отсутствия всех уязвимостей продукта. Не выполнялись независимый пентест, динамическое DAST-сканирование, анализ сторонних библиотек и ручная проверка всех возможных плагинов/будущих API.

В этом рабочем окружении недоступны локальная Rust-сборка с Cargo и действующая серверная сессия пользователя. До успешного завершения CI и контрольного входа с ролью `viewer` нельзя считать исправления полностью проверенными в эксплуатации.

**Рекомендация для эксплуатации:** сначала обновить панель на стенде, дождаться успешного Backend CI, войти тестовым наблюдателем и проверить отсутствие приватных значений в Network → Response для `bootstrap`, `settings` и `collections/*`. Отдельно убедиться, что действующие подписки и доступ администратора не изменились.
