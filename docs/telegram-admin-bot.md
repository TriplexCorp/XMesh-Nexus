# Встроенный административный Telegram-бот XMesh Nexus

Бот запускается внутри Rust-бэкенда панели. Отдельный контейнер, webhook, открытый порт или изменение .env не требуются.

## Настройка

1. Создайте отдельного бота в @BotFather и скопируйте токен.
2. В XMesh Nexus откройте «Система → Telegram-бот».
3. Вставьте токен и введите числовые Telegram user ID доверенных администраторов — по одному на строку.
4. Включите бот и нажмите «Сохранить и применить». Панель зашифрует токен, запустит long polling и покажет имя бота и состояние подключения.
5. Откройте личный чат с ботом от разрешённого Telegram-аккаунта и отправьте /start.
6. **При первом обращении бот предложит выбрать 🇷🇺 Русский / 🇬🇧 English.** Выбор сохраняется отдельно для каждого Telegram-администратора и не сбрасывается при перезапуске панели. Позже можно изменить его через /language или кнопку «Язык».

Бот автоматически отключает старый webhook через deleteWebhook(drop_pending_updates=false), поскольку использует Telegram long polling. **Не используйте один токен одновременно в других сервисах.**

## Команды

| Команда | Действие |
| --- | --- |
| /start или /menu | Интерактивное меню |
| /stats | Количество пользователей и нод, отключённые и ожидающие пользователи |
| /users | Восемь последних пользователей и кнопки карточек |
| /find username | Поиск по имени |
| /user 123 | Карточка, трафик, срок действия, состояние |
| /nodes | Список нод и сохранённый статус (не live heartbeat) |
| /enable 123 | Включение с одноразовым подтверждением |
| /disable 123 | Отключение с одноразовым подтверждением |
| /squads | Просмотр сквадов |
| /findtg 123456789 | Поиск всех пользователей с Telegram ID |
| /create customer 30 | Создание нового VPN-пользователя на 30 дней с новыми независимыми протокольными ключами и подпиской |
| /renew 123 30 | Продление пользователя на 30 дней с проверкой статуса |
| /quota 123 50 | Изменение общего лимита на 50 ГБ (0 = безлимит), без обнуления трафика |
| /language | Смена языка RU / EN |

## Защита

- Конфигурацию может читать и изменять только владелец панели, с обычной защитой сессии и Origin.
- Токен хранится как AES-256-GCM ciphertext с ключом, отделённым от шифрования подписок. В UI и журнал аудита токен не возвращается.
- Команды принимаются только в личных чатах с разрешёнными числовыми Telegram user ID; неразрешённые отправители игнорируются.
- Redis ограничивает частоту запросов и запрещает действия при недоступности лимитера.
- PostgreSQL advisory lock позволяет только одному экземпляру бэкенда опрашивать Telegram.
- Подтверждения любых изменений (создание, продление, лимиты, включение/отключение) действуют 60 секунд, привязаны к ID администратора и одноразово погашаются внутри транзакции. Во время записи права администратора дополнительно проверяются и блокируются против гонок с отзывом доступа.
- Нельзя через бота удалить пользователя или ноду, прочесть Xray UUID, приватные ключи, выполнить shell-команду, изменить устройство/Xray или произвольно изменить запись пользователя. Доступны только явно указанные операции с ограниченными значениями.
- Все изменения логируются в panel_audit_log. Создание пользователя и выпуск подписки выполняются атомарно, в одной транзакции PostgreSQL. Продление не меняет бессрочные аккаунты и подписки с отсроченным стартом.
- Используйте только выделенного Telegram-бота. Для администрирования добавляйте исключительно доверенные Telegram ID.

## Диагностика

«Подключение…» — проверьте исходящий HTTPS-доступ сервера к api.telegram.org, DNS и firewall.
«Токен отклонён» — создайте новый токен в BotFather и сохраните его.
«Telegram API недоступен» — убедитесь, что этот же токен не использует второй сервис.
Нет ответа — проверьте, что добавлен числовой ID пользователя Telegram (а не группы), и пишите в личный чат.

Бот перезапускает подключение автоматически. Для дополнительных прав, ролей команд и управления инфраструктурой понадобится отдельный строго ограниченный релиз.

## Языки и режимы

Все основные меню и сообщения бота поддерживают русский и английский. Язык выбирается при первом запуске и хранится в БД по Telegram user ID. Новые администраторы до выбора языка не получают административные команды. Вызов /language предлагает сменить язык в любой момент.

Границы текущей версии: нет удаления пользователей, импорта/экспорта базы, произвольных команд нодам, обновления Xray, полного CRUD сквадов и административной смены VPN-секретов. Для них потребуются отдельные scopes и меры подтверждения; не следует считать встроенный бот альтернативой всем настройкам веб-панели.
