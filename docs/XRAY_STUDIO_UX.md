# XRAY STUDIO — утверждённый дизайн 2 в 1

## Концепция
Единственный утверждённый интерфейс — JSON-first рабочая область: основной JSON-редактор слева, серверный конструктор справа, отдельная узкая панель Tools ещё правее. Панели JSON и конструктора работают одновременно. Профили и шаблоны открываются отдельными диалогами, чтобы не занимать постоянную колонку.

## Обязательные свойства
- **JSON — источник истины.** Ручные правки сразу обновляют поля конструктора, когда конфигурация синтаксически корректна. Изменение поля конструктора меняет только соответствующие JSON-поля.
- В случае ошибки синтаксиса исходный текст сохраняется. Конструктор не перезаписывает некорректный JSON.
- Неизвестные поля, дополнительные inbounds, outbounds, routing.rules и иные сложные параметры нельзя терять при обычных изменениях.
- **Зона клиентов и ручные UUID отсутствуют.** Пользователи, их UUID и привязка к inbound управляются вне XRAY STUDIO. При создании серверного шаблона массив clients остаётся пустым.
- Tools предназначены для серверной конфигурации: Reality X25519, Short ID, DNS, Routing, Policy / Stats, Outbounds, проверка. Контекстные изменения применяются к выбранному inbound.
- Редактор имеет подсветку JSON, номера строк, форматирование, Undo/Redo, импорт, экспорт, полноэкранный режим и видимый статус несохранённых изменений.
- Сохранение профиля не является применением его на узлах. Статус интерфейса не должен утверждать, что Xray-core проверил конфигурацию, если не выполнен реальный xray run -test.
- UI использует существующую тему, масштабы и RU/EN инфраструктуру панели, без жёсткой зелёной палитры.

## Реализация
- `xray-studio-v4.js`: JSON-first редактор, форма, управление профилями, импорт/экспорт и синхронизация.
- `xray-studio-v4.css`: утверждённая трёхпанельная рабочая область.
- `xray-studio-tools.js`: набор безопасных инструментов с историей.
- `app.js`: подключение страницы.
- `backend/Dockerfile` и `backend/src/security.rs`: поставка статических файлов и работа скрытого пути панели.

## Ещё требуется проверить на настоящем браузере и сервере
- Экраны 3440×1440, 1920×1080 и мобильный, настройки масштаба.
- Сохранение, выбор, создание и редактирование профилей с PostgreSQL.
- Режимы Reality, XHTTP, TLS, несколько inbound/outbound и сохранение неизвестных JSON-полей.
- Работоспособность всех действий Tools и отзывчивость синтаксической подсветки на больших конфигах.
- Полную проверку JSON через запущенный Xray-core, а не только статический анализ.
- RU/EN-перевод новых строк и доступность управления с клавиатуры.

**Правило:** не возвращаться к прежней отдельной форме/JSON и не добавлять клиентскую зону.
