# XRAY STUDIO — редактор конфигураций (решение по UX)

## Цель
XRAY STUDIO — единая рабочая среда редактирования профилей Xray. Нельзя одновременно принуждать пользователя работать с формой, списком профилей и дублированным JSON на трёх постоянных колонках.

## Основная модель
- Два независимых режима: **Конструктор** и **Редактор JSON**.
- В режиме **Конструктор** основной экран — форма с вкладками Основное, Защита и транспорт, Клиент. Предпросмотр Server/Client JSON открывается только по запросу.
- В режиме **Редактор JSON** основная область — один широкий исходный JSON. Никакого второго зеркального окна.
- Библиотека профилей — дополнительная открываемая панель, а не постоянно видимый столбец.
- Одна верхняя панель действий: открыть профили, проверить, форматировать, импортировать, экспортировать, открыть предпросмотр.
- Одна нижняя панель сохранения с честным статусом: сохранение профиля **не** применяет конфигурацию автоматически на узлах.

## Инварианты
1. Импортированный JSON нельзя молча преобразовывать обратно в визуальные поля с потерей расширенных опций.
2. Существующий профиль открывается как исходный JSON (без удаления неизвестных полей).
3. Изменения сохраняются в существующее хранилище профилей через API.
4. Проверка структуры JSON в браузере не равна валидации через живой Xray-core.
5. Клиентский JSON при произвольном серверном JSON не следует выдавать как гарантированно корректный.
6. Нельзя выдумывать фиктивные профили, хосты или пользователей для пустой установки.

## Критерии готовности следующего этапа
- e2e-проверка переключений и всех действий на экранах 3440×1440, 1920×1080 и мобильном размере;
- проверка сохранения/редактирования/импорта без потери JSON;
- проверка Xray-конфигураций через Xray-core с понятной ошибкой;
- подсветка JSON, номера строк, диагностика ошибок с позициями;
- проверка RU/EN и всех тем/настроек масштаба;
- отдельные серверные интеграционные тесты для генерации VLESS, XHTTP, Reality, VLESS Encryption.
