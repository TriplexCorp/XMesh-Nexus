# Динамические Remark в XMesh Nexus

В разделах Хосты → Подключение и XRAY STUDIO → Публичные подключения поле Название / Remark поддерживает динамические переменные. Подстановка выполняется при каждом запросе подписки, но сохранённый шаблон Host остаётся неизменным.

Пример: 🇩🇪 Германия · {STATUS_EMOJI} {USERNAME} · {DATA_LEFT} · {DAYS_LEFT} д.

## Переменные

| Переменная | Назначение |
| --- | --- |
| {SERVER_IP} | Публичный IPv4 прямого подключения |
| {SERVER_IPV6} | Публичный IPv6 прямого подключения |
| {USERNAME} | Имя пользователя |
| {DATA_USAGE} | Использованный трафик |
| {DATA_LEFT} | Остаток трафика |
| {DATA_LIMIT} | Лимит трафика |
| {DAYS_LEFT} | Оставшиеся дни (округление вверх) |
| {TIME_LEFT} | Дни, часы и минуты |
| {EXPIRE_DATE} | Дата окончания (UTC) |
| {JALALI_EXPIRE_DATE} | Дата по календарю Джалали |
| {STATUS_TEXT} | Текущий статус пользователя |
| {STATUS_EMOJI} | Настраиваемый эмодзи статуса |
| {PROTOCOL} | Протокол подключения |
| {TRANSPORT} | Транспорт Xray |

Данные usage/limit берутся из учёта трафика пользователя, который включается в формирование подписки. Единицы — десятичные ГБ. При отсутствии лимита/срока выводится ∞. Подписки с отсчётом от первого подключения показывают отдельный статус ожидания.

## Настройка эмодзи

В SUBSCRIPTION STUDIO → Клиентский портал → Эмодзи статусов в Remark редактируются значения ACTIVE (✅), ON_HOLD (⌛️), LIMITED (🪫), EXPIRED (❌), DISABLED (🔌). Данные сохраняются в subscriptionStatusEmojis в настройках панели, без правок .env.

## Безопасность и совместимость

- Серверные подстановки касаются только клиентского имени; Xray routing tags и UUID не меняются.
- Для CDN-домена и hostname {SERVER_IP}/{SERVER_IPV6} показывают —. Скрытый IP origin-ноды не раскрывается.
- Неизвестные переменные остаются без изменений. Подстановка однопроходная, без рекурсии.
- Итоговое имя ограничено 100 символами; управляющие символы удаляются.
- Изменения видны после следующего обновления подписки клиентом, не мгновенно.
- Публичная выдача по-прежнему блокируется для отключённых/истёкших пользователей согласно существующей политике доступа.
